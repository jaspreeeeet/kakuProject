3. HEALTH / SICK / DISCIPLINE / STATS_MENU SYSTEM  [Commit: 5d66488]
─────────────────────────────────────────────────────────────────────────────

OVERVIEW:
Complete game mechanics overhaul: sickness system, hunger pausing, health
drain, discipline tracking, and a new STATS_MENU with visual progress bars.

SICK_PENDING RULES:
  Triggers when EITHER:
    - Poop present for > 15 minutes without cleaning
    - Pet health < 40

HUNGER PAUSE:
  - Hunger does NOT increase while sick_pending = true OR poop_present = true
  - Prevents double-penalizing player during crisis state

HEALTH DRAIN:
  - If pet not fed within 30 minutes -> health -2 per daemon cycle
  - Encourages regular feeding

DISCIPLINE SYSTEM:
  - New discipline column added to database (0-100)
  - Daemon rules per cycle:
      Not fed in time     -> discipline -2
      Poop not cleaned    -> discipline -3
      Not played in 1hr   -> discipline -1
      All needs met       -> discipline +1

NEW MENU: STATS_MENU
  - Menu position: between STATUS_INFO_MENU and MAIN (wraps around)
  - Full menu cycle:
      MAIN -> FOOD -> TOILET -> PLAY -> HEALTH -> STATUS_INFO -> STATS -> MAIN
  - Displays two animated bar graphs:
      Happiness bar  (left label "H")
      Discipline bar (right label "D")
  - drawBar(x, y, w, h, value) renders filled rectangle scaled to value/100

ESP32 GLOBALS ADDED:
  int petHappiness  = 50
  int petDiscipline = 50

SERVER RESPONSE UPDATED (/api/oled-display/get):
  + happiness
  + discipline
  + show_play_icon

FILES MODIFIED:
  - esp32_sketch.ino (STATS_MENU, drawBar, petHappiness, petDiscipline)
  - app.py (discipline column, daemon logic, OLED response)

5. OLD PET EMOTION SPRITES  [Commits: fb0764b, 402e5e6]
─────────────────────────────────────────────────────────────────────────────

OVERVIEW:
Replaced generic fallback animations for OLD-age pet with proper emotion
sprites. All new arrays are 64x32, 2 frames, 256 bytes/frame, 100ms delay.

NEW ARRAYS ADDED TO all_pets.h:

  old_happy[2][256]
    - Used for: IDLE state, HAPPY emotion, default animation
    - Animated: cycles between frame 0 and frame 1

  old_sad[2][256]
    - Used for: SAD, HUNGER, POOP emotions
    - Replaces the drawSimpleSadFace() fallback for OLD age

  old_cry[2][256]
    - Used for: CRY emotion
    - Priority: OLD+CRY branch fires before generic CRY branch

  old_surprise[2][256]
    - Used for: SURPRISE emotion
    - Non-OLD ages fall back to: infant_surprise_frames

NEW DEFINES PER ARRAY:
  OLD_HAPPY_FRAME_COUNT / OLD_HAPPY_WIDTH / OLD_HAPPY_HEIGHT
  OLD_SAD_FRAME_COUNT   / OLD_SAD_WIDTH   / OLD_SAD_HEIGHT
  OLD_CRY_FRAME_COUNT   / OLD_CRY_WIDTH   / OLD_CRY_HEIGHT
  OLD_SURPRISE_FRAME_COUNT / OLD_SURPRISE_WIDTH / OLD_SURPRISE_HEIGHT

ANIMATION SWITCH ORDER IN esp32_sketch.ino:
  1. CRY + INFANT         -> infant_cry_frames
  2. CRY + OLD            -> old_cry
  3. SURPRISE + OLD       -> old_surprise
  4. SURPRISE (any age)   -> infant_surprise_frames (fallback)
  5. SAD / HUNGER / POOP  -> age switch: OLD->old_sad, INFANT->infant_sad, others->drawSimpleSadFace()
  6. IDLE                 -> age switch: OLD->old_happy[0] static, others->age_frames[0]
  7. default (HAPPY)      -> age switch: OLD->old_happy animated, others->age_frames animated

FOOD_MENU UPDATE:
  OLD + hungry     -> old_cry
  OLD + not hungry -> old_happy[0]

FILES MODIFIED:
  - all_pets.h (4 new arrays + defines, 228 lines added)
  - esp32_sketch.ino (animation switch branches for OLD age)
  - test_all_animations.ino (4 new OLD pet entries)
